# 📄 PDF AI Chatbot (RAG System)

This project is a web-based PDF question-answering system built using Flask and Ollama.

## 🚀 Features

* Upload PDF files
* Ask questions based on PDF content
* AI-powered answers using Llama3 (Ollama)
* Simple chat-style interface

## 🛠️ Technologies Used

* Python (Flask)
* PyPDF
* Ollama (Llama3)
* HTML/CSS

## ▶️ How to Run

1. Install dependencies:

```
pip install flask pypdf requests
```

2. Install Ollama:
   https://ollama.com/

3. Run model:

```
ollama run llama3
```

4. Run app:

```
python app.py
```

5. Open in browser:
   http://127.0.0.1:5000

## 📌 Notes

* Make sure Ollama is running before asking questions
* This project works locally
